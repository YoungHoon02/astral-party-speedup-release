Astral Party Anim Speed - 사용 전 안내

이 모드는 Astral Party의 비공식 사용자 제작 모드입니다. 게임 제작사나
운영사가 제공하거나 지원하는 제품이 아닙니다. 설치 전에 아래 내용을
확인해 주세요.

1. 모드의 범위
   이 모드는 사용자의 게임 클라이언트에서 게임의 진행 속도를
   조절해 연출과 이동, 화면 전환을 빠르게 만듭니다. 턴 타이머는 배속과 분리해 실제
   시간으로 유지하려고 하지만, 모든 게임 버전·플레이 상황에서 같은 결과를
   보장하지는 않습니다. 온라인 플레이 시에도 게임 운영 정책과 다른 플레이어를
   존중해 주세요.

   이 모드는 게임과 서버 사이의 통신에 관여하지 않습니다(플러그인에 네트워크
   코드가 없습니다). 게임 패킷을 읽거나 쓰지 않고, 키 입력을 자동화하지도
   않습니다.

2. 설치와 설정
   BepInEx 및 .NET Desktop Runtime은 별도로 설치해야 합니다.
   배속 등 사용자 설정은 모드 폴더의 config.json에 저장됩니다.
   이 파일은 첫 실행 때 만들어지며 업데이트해도 덮어쓰지 않습니다.
   자세한 절차는 함께 제공되는 HOW_TO_INSTALL.txt를 참고하세요.

3. 업데이트 확인
   설정 앱은 실행 시 공개 GitHub 배포 저장소의 release-index.json을
   읽어 새 버전이 있는지 확인합니다. Download 버튼은 브라우저에서
   배포 ZIP의 다운로드 주소를 엽니다. 업데이트 파일을 자동으로
   설치하지 않습니다.

4. 문제 발생 시
   게임 또는 BepInEx 업데이트 이후 모드가 작동하지 않거나 게임 실행에
   문제가 생길 수 있습니다. 문제가 생기면 게임을 종료하고 모드 폴더를
   제거하거나 이전 버전으로 되돌린 뒤 로그를 확인해 주세요.
   게임 업데이트 뒤에는 BepInEx\LogOutput.log의 [status] 줄로 모드 상태를
   확인할 수 있습니다.

5. 이용 조건
   이 안내문은 모드의 이용·복제·수정·재배포에 새로운 제한을
   추가하지 않습니다. 적용되는 라이선스는 배포 저장소의 표기를
   확인해 주세요. 게임과 BepInEx에는 각각 별도의 조건이 적용됩니다.
   https://github.com/YoungHoon02/astral-party-speedup-release

이 모드는 별도 보증 없이 제공됩니다. 사용 중 문제가 생기면 게임을
종료한 뒤 모드를 제거해 주세요.
