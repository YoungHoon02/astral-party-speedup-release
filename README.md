# Astral Party 배속 모드

Astral Party의 캐릭터/애니메이션 재생 속도를 조절하는 BepInEx 모드입니다.
다른 플레이어의 턴을 포함해 애니메이션이 빠르게 재생되어 대기 시간이 줄어듭니다.

> 이 저장소는 **배포 전용**입니다. 소스 코드는 포함되어 있지 않습니다.

## 다운로드

**[최신 버전 받기](../../releases/latest)**

## 설치

1. 게임에 **BepInEx 6 (IL2CPP)** 가 먼저 설치되어 있어야 합니다.
2. 받은 zip을 **게임 설치 폴더**(`AstralParty_INT.exe`가 있는 곳)에 그대로 풀어주세요.
3. 게임을 실행하면 배속 설정 창이 같이 뜹니다.

zip 안의 `설치방법.txt`에 더 자세한 안내가 있습니다.

## 사용법

게임 실행 시 함께 뜨는 설정 창에서 배속(1x ~ 5x)을 고르고 **Save**를 누르면
몇 초 안에 게임에 적용됩니다.

- 설정 창을 닫으면 배속은 자동으로 **1x로 초기화**됩니다.
- 로비/매칭 화면에서는 배속이 걸리지 않습니다.
- 화면 하단의 턴 타이머는 배속과 무관하게 **실제 시간**으로 흘러갑니다.

## 업데이트 확인

설정 창을 열 때 새 버전이 있는지 자동으로 확인하고, 있을 때만 알림이 표시됩니다.
확인에 실패하거나 최신 버전이면 아무것도 표시되지 않습니다.

버전 정보는 `distribution` 브랜치의 [`release-index.json`](../../blob/distribution/release-index.json)
하나만 읽습니다. `api.github.com`은 미인증 시 IP당 시간당 60회 제한이 있어서,
`raw.githubusercontent.com`(CDN)에서 읽어 이 제한을 받지 않습니다.
